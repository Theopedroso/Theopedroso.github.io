Oliver.Painel do portfólio

Entrar

Conecte-se uma vez para gerenciar as fotos do seu site. Sua chave fica salva só neste aparelho.

Como criar a chave de acesso (1ª vez)
  1. Abra github.com/settings/personal-access-tokens/new (logada na conta dona do site).
  2. Em Token name, escreva algo como painel-oliver. Em Expiration, escolha o prazo (ex.: 1 ano).
  3. Em Repository access → Only select repositories → escolha Theopedroso.github.io.
  4. Em Permissions → Repository permissions → Contents → selecione Read and write.
  5. Clique em Generate token, copie o código e cole aqui em cima. Pronto! 🎉
